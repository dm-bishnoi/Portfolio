01 — About

I work across the full stack, and care about how things feel.

From shaping product interfaces in Angular to wiring APIs in Node and persisting data in MongoDB or PostgreSQL — I like the work where design, engineering, and product thinking meet.

These days I'm especially interested in the seam between traditional web engineering and AI-powered products. How do you build an interface that still feels calm, fast, and considered when there's an LLM in the loop?

  • Product-minded engineer

    I think about the user before the framework. Decisions flow from the problem, not the other way around.

  • Calm, considered UI

    Restrained motion, honest typography, generous spacing. The interface should disappear, the work shouldn't.

  • End-to-end ownership

    From a TypeScript interface to a Postgres index — I'll happily own the whole loop, and the boring parts in between.
